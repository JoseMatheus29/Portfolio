<Decisao titulo="Sem API do Jira na primeira versão">
A pessoa cola o código ou o link do card. Assim, o app não depende de token nem de autorização da TI.
</Decisao>

<Decisao titulo="Banco só no processo principal">
Todo o SQL fica no processo principal do Electron, e a interface acessa os dados por uma ponte tipada, com `contextIsolation` e `sandbox` ligados.
</Decisao>

<Decisao titulo="Regras de tempo como funções puras">
As regras de sessões e métricas não dependem de banco, de Electron nem de React, o que permite testá-las isoladamente.
</Decisao>
