<Decisao titulo="Dos dados no aparelho para uma API com login">
O app usava SQLite, e o único backup era um arquivo exportado à mão. Com a API, trocar de celular não faz perder nada. Em troca, sem internet o app não mostra os dados.
</Decisao>

<Decisao titulo="Repetir uma gravação não duplica a despesa">
Se a rede cair, o app reenvia a mesma `Idempotency-Key`, e a API devolve a resposta original em vez de gravar outra vez.
</Decisao>

<Decisao titulo="A despesa das 22h que caía no mês errado">
No último dia do mês, 22h em Brasília já é o dia seguinte em UTC. A correção foi gravar a data que a pessoa vê como meio-dia UTC daquele dia.
</Decisao>

<Decisao titulo="Testes em um Postgres de verdade">
Os testes de integração usam um banco real, para validar locks, `FOR UPDATE` e buscas com `unaccent`.
</Decisao>
